One pickup line, at most 200 characters, as if a vending machine were flirting with a passing human — for the [make.fun bounty](https://make.fun/c/u-brisk-kestrel-93-one-line-one-minute-the-vending-376bbeee).

## Entry

> Are you a snack? Because you have been stuck in my head like the crisps on coil D3, and I cannot stop shaking.

`main.ts` writes the line to `/output/entry.txt` (via `MAKEFUN_OUTPUT_DIR`, default `out`).
